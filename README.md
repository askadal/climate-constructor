# Симулятор микроклимата

Иллюстрированная интерактивная модель Савёловской площади. Статический сайт: сборка, серверная часть и установка зависимостей не требуются.

- `index.html` — основное приложение со встроенными моделью, расчётами, интерфейсом и текстурами.
- `objects.html` — галерея объектов.
- `assets/` — исходные рисованные текстуры и описание их создания.
- `docs/` — описание реализации и отчёты проверок.
- `ATTRIBUTION.txt`, `THREE-LICENSE.txt`, `UTCI-LICENSE.txt` — сведения об источниках и лицензиях.

## Замена содержимого репозитория

Распакуйте архив. Поместите его содержимое в корень репозитория: файл `index.html` должен находиться непосредственно в корне, без дополнительной папки. Загружайте распакованные файлы, а не сам ZIP. Существующие настройки публикации и собственный файл `CNAME`, если он используется, сохраните.

Для GitHub Pages используйте публикацию корня репозитория. Объекты, которые посетитель добавляет в сцену, живут только в его текущем сеансе.

## Версия от 18 октября 2026

Фасады осветлены на 70% от `#dbd7bb` к белому: базовый цвет `#f4f3eb`; освещение и тени изменяют их видимый оттенок. Включены рисование газона и кустов от руки, сглаживание контура, обновлённые деревья, исправления тротуаров и переходов и все текущие инструменты моделирования.

Численные формулы расчёта не менялись при обновлении цвета. Результаты остаются оценками существующей модели с её допущениями; описание реализации находится в `docs/DEVELOPMENT.md`.
